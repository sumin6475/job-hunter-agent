# Role Context and Product Involvement
As a **Senior Full-Stack Software Engineer**, you will:  
- **Zero-to-one features:** Design & build new platform modules (data pipelines, annotation UI, model-management APIs).  
- **End-to-end ownership:** From database schema and backend services (Node.js / Python / Go) through React/TypeScript front end and CI/CD.  
- **Cross-functional collaboration:** Partner with ML Engineers, Data Scientists, SRE, Product & UX to ship enterprise-grade vision solutions.  
- **Technical mentorship:** Guide junior engineers, conduct code reviews, write documentation, uphold best practices.  
- **Scale & Security:** Ensure the platform scales to terabytes of image/video data and complies with SOC 2, custom security rules.
